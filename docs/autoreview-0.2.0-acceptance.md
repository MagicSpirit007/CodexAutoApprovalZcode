## 边界和回退

首期支持 Windows x64 本地工作区，不添加数据库迁移。公开基线的 Computer Use 为 unavailable 占位，未验证完整 Computer Use。安装器使用独立产品身份，没有沿用官方程序签名。

首次迁移仍须运行独立安装器。旧便携目录保留；安装器副本保存于 `%LOCALAPPDATA%\ZCode AutoReview\installers`。发生安装或启动故障时可使用已验证副本修复；数据兼容版本可关闭应用后手动回退。更新器禁止自动降级。

稳定索引只在固定版本 Release 资产重新下载并完成校验后推进；发布结果另见交付目录 PUBLISHED.json。
