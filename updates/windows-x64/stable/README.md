# 独立稳定更新索引

本目录只分发 ZCode AutoReview Windows x64 稳定版。`latest.yml` 由手动发布工具在 Release 下载和全部验收门禁通过后推进；插件发行不更新此索引。首版安装器验收完成前不提交指向尚未上传资产的有效清单。

身份：`dev.codexautoreview.zcode`。标签：`autoreview-v<发行版本>`。兼容元数据及固定资产 URL 的合同见 `packages/shared/src/auto-review-distribution.ts`（源码补丁）和 `docs/distribution-upgrades.md`。
